# Mediciones Tabian

App web (PWA) de mediciones, actas de conformidad y ofertas de precios de TABIAN.
Publicada en https://mediciones.tabian.es

- `index.html` · la app
- `config.js` · ID de cliente de Google y URL del Apps Script
- `apps-script/Codigo.gs` · API que va pegada en la hoja "Mediciones Tabian" (Extensiones > Apps Script)

Los datos están en la hoja de Google y los PDF en Drive; aquí solo está el código.
